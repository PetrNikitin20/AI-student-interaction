# Исследовательское партнёрство студента с ИИ

Репозиторий содержит полный воспроизводимый комплект данных, документов и кода к статье «Исследовательское партнёрство студента с искусственным интеллектом».

## Статус данных

Все построчные записи в репозитории являются **синтетической реконструкцией** значений, заявленных в статье. Они позволяют проверить арифметику, статистический анализ, таблицы и графики, но не подтверждают факт проведения исследования с участием людей. Подробности приведены в [DATA_STATUS.md](DATA_STATUS.md).

## Что воспроизводится

| Показатель | Экспериментальная группа | Группа сравнения |
|---|---:|---:|
| Участники | 27 | 29 |
| Проверенные ссылки | 298 из 310 | 290 из 368 |
| Неподтверждённые утверждения | 38 на 78 924 слова | 145 на 90 188 слов |
| Успешное воспроизведение | 22 из 27 | 13 из 29 |
| Обоснованный выбор модели | 25 из 27 | 16 из 29 |

Дополнительно воспроизводятся входной, итоговый и отложенный тесты, ИИ грамотность, задача переноса, две экспертные оценки по восьми шкалам, четыре графика, ANCOVA, размеры эффектов, OR, IRR, ICC и разведочная регрессия.

## Состав репозитория

- `article/Итоговая_статья.docx` — версия статьи, на основании которой собран комплект.
- `documents/01_Протокол_апробации.docx` — дизайн, выборка, измерения, процедура и статистический план.
- `documents/02_Инструментарий_анкеты_тесты_рубрики.docx` — формы согласия, тестовые формы, рубрика, журнал ИИ, проверка ссылок, воспроизведение и интервью.
- `documents/03_Отчет_о_воспроизводимости.docx` — результаты 62 автоматических проверок.
- `data/Полный_массив_апробации.xlsx` — единая книга со сводкой, всеми таблицами и графиками.
- `data/*.csv` — первичные построчные таблицы.
- `code/` — генерация, анализ, графики, документы, Excel и контроль заявлений.
- `results/VALIDATION_REPORT.md` — машиночитаемый журнал соответствия числам статьи.
- `figures/` — четыре графика статьи.

## Воспроизведение анализа

Требуется Python 3.11 или новее.

```bash
python -m pip install -r code/requirements.txt
python code/generate_participant_data.py
python code/build_detailed_records.py
python code/analysis.py
python code/make_figures.py
python code/validate_article_claims.py
```

Успешный последний шаг возвращает:

```json
{
  "status": "PASS",
  "checks_total": 62,
  "checks_passed": 62,
  "checks_failed": 0
}
```

## Переход к фактическим данным

Для эмпирической версии следует заменить синтетические CSV фактическими обезличенными записями, приложить решение этической комиссии или обоснование освобождения, реальные формы согласия, метаданные сбора и неизменяемый аудиторский след. После замены данных весь анализ необходимо выполнить повторно, сохранив нулевые и отрицательные результаты.
